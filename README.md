# 淘宝评价素材整理工具

> 版本：**v0.1（内测版）** · 本地离线桌面工具

面向淘宝运营/评价维护场景的素材管理小工具：按店铺组织评价素材记录，支持图片截图直接粘贴进表格、按标题搜索、一键导出 Excel，全部数据保存在本地，不上传任何内容。

---

## 功能特性

- **店铺管理**：新增、重命名、删除店铺；店铺树实时显示素材数量，双击可展开/收起，标题栏支持一键全部展开/折叠；**右键店铺可快速重命名**
- **素材记录管理**：每条记录含 8 个字段——商品ID、规格图、规格、标题、链接主图、补手、买家秀评价、图片；支持新增、**修改、复制（按钮或右键，复制会在原行下方生成一条相同记录并弹出表单可再调整）**、删除；其中**评价图片支持添加多张，表格内全部并排显示**
- **自适应表格**：行高随评价文字长短与评价图片张数自动变化（长文本自动换行、多图自动换行并增高），拖动列宽或缩放窗口时自动重排，始终保持整齐
- **表格选择**：点内容单元格只选中该格；**点顶部字段名选中该列全部数据，点最左侧行号（1/2/3…）选中整行**；无论光标落在哪个单元格，右键或点「修改记录」都编辑该条记录；表格内容不可就地改写，统一走弹窗
- **图片粘贴**：选中图片格后直接 **Ctrl+V**（也可双击占位格或右键粘贴），即可把剪贴板截图保存进本地并显示缩略图；要一次追加多张点格内「+」从文件选择
- **图片管理**：多张评价图片在格内并排显示、超出自动折叠可展开；**双击缩略图复制图片到剪贴板**，右键可查看大图（超过 800px 自动缩放，多张可翻页）、粘贴、**删除此图片**（精确删除右键的那张）或修改该条记录
- **商品勾选（批量选择）**：表头只有一个小方框（位于「商品ID」表头）：点一下出现每行勾选框并默认全选，底部实时显示已选条数；手动取消个别行后表头变半选、再点补齐全选；**全选状态下再点一下即退出批量选择、勾选列消失，回归普通状态**
- **标题搜索**：按标题关键词实时过滤当前店铺的记录，支持一键清除
- **导出 Excel**：将当前店铺全部素材记录导出为 `.xlsx`（带表头加粗与列宽优化）
- **现代界面**：统一浅色主题（卡片式面板、圆角控件、状态色按钮），支持自定义 `app/style.qss`
- **性能优化**：图片缩略图懒加载（仅渲染可见区域）+ 全局解码缓存，几百条记录的大店铺滚动、搜索、刷新也不卡顿

## 项目结构

```
taobao-material-tool/
├── main.py                  # 程序入口（启动应用、加载 QSS 与素材）
├── requirements.txt         # 依赖清单
└── app/
    ├── config.py            # 全局配置：路径、表格列定义、导出列宽
    ├── storage.py           # 数据层：JSON 读写 + 店铺/记录增删改查
    ├── services.py          # 服务层：图片保存、Excel 导出
    ├── assets/              # 界面图标素材（复选框三态等）
    └── ui/
        ├── main_window.py   # 主窗口：界面组装与业务流程编排
        ├── record_table.py  # 素材表格：勾选列、渲染、图片单元格、搜索
        ├── flow_layout.py   # 流式布局：多图自动换行、行高自适应
        ├── add_dialog.py    # 新增/修改素材记录弹窗（缩略图选择器、多图添加器）
        └── image_utils.py   # 图片按尺寸解码 + 全局缩略图缓存（表格/弹窗共用）
```

代码按「界面层 / 数据层 / 服务层」分层，后续新增字段只需修改 `app/config.py` 中的 `RECORD_FIELDS` 与 `TABLE_HEADERS`，表格渲染、搜索、导出自动跟随。

## 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/GelunPan/taobao-material-tool.git
cd taobao-material-tool

# 2. 安装依赖（建议使用虚拟环境）
pip install -r requirements.txt

# 3. 运行
python main.py
```

> 依赖：`PyQt6>=6.5`、`openpyxl>=3.1`。首次启动会自动创建 `data/` 目录。

## 使用说明

1. **新建店铺**：点击左侧「+ 新店铺」，输入店铺名称
2. **选择店铺**：点击左侧店铺名，右侧表格展示该店铺的素材记录
3. **新增记录**：点击「新增记录」，填写商品ID、规格、标题、补手、评价等文本字段；规格图、链接主图各选一张（弹窗内直接显示缩略图），**评价图片可多次「+ 添加图片」选择多张，每张可单独点 × 删除**
4. **修改/复制/删除记录**：点中该条记录的任意单元格（或点行号选中整行、点字段名选中整列），点击「修改记录」「复制记录」「删除记录」按钮；也可以在任意单元格上**右键**弹出菜单操作。
   - **复制记录**：和修改一样弹出已填好的表单，可原样确认或微调，确定后在原记录**正下方**生成一条相同的新记录并自动选中
5. **图片操作**：复制截图后点选图片格按 **Ctrl+V** 粘贴，点格内「+」从文件追加多张；**双击缩略图复制图片**，右键可查看大图、删除该张或修改记录
6. **搜索**：在右上角搜索框输入标题关键词，点击「搜索」过滤记录；「清除搜索」恢复全部
7. **导出**：点击「导出Excel」，选择保存位置，生成当前店铺全部记录的 `.xlsx` 文件

> 数据安全：所有数据保存在程序目录下的 `data/` 中，图片字段记录的是本地文件路径。**请勿在未备份的情况下移动或删除 `data/` 目录及其图片文件**，否则缩略图会失效。

## 版本记录

### v0.1（内测版）
- ✅ 首版功能：店铺管理、素材记录增删改、右键快捷菜单（记录修改/删除、店铺重命名）、图片粘贴与预览、标题搜索、Excel 导出
- ✅ 评价图片支持多张（弹窗多选添加、表格内全部并排显示并随张数自动换行增高、双击大图翻页）；旧版单图数据在加载时自动迁移，无需手动处理
- ✅ 双击店铺可展开/收起，配合标题栏一键全部展开/折叠
- ⚠️ 内测说明：功能可用但未经过大规模数据验证；`data.json` 数据格式可能随版本演进调整，**升级前请备份 `data/` 目录**
- 📌 已知限制：
  - 搜索仅支持标题字段
  - 导出仅支持当前店铺（不支持全店铺/多选导出）
  - 图片以本地路径引用，移动图片文件后缩略图失效
  - 记录字段目前固定为 8 列，暂不支持自定义列
