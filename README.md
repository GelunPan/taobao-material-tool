# 淘宝评价素材整理工具

> 版本：**v0.2（内测版）** · 本地离线桌面工具

面向淘宝运营/评价维护场景的素材管理工具：按店铺组织评价素材记录，支持截图直接粘贴进表格、按标题搜索、一键导出 Excel；内置淘宝登录与商品素材抓取（基于 Playwright 驱动本机真实 Chrome，规避风控）。全部数据保存在本地，不上传任何内容。

---

## 功能特性

### 素材管理（核心）

- **店铺管理**：新增、重命名、删除店铺；店铺树实时显示素材数量；**拖拽店铺标签可排序**（带淡入高亮动效）；双击展开/收起；**右键店铺可设置填充色和字体颜色**，方便区分不同店铺
- **素材记录管理**：每条记录含 9 个字段——商品ID、规格图、规格、标题、链接主图、补手、买家秀评价、评价图片、商品链接；支持新增、修改、**复制（在原行下方生成相同记录并弹出表单可微调）**、删除；**评价图片支持多张**，表格内并排显示
- **自适应表格**：行高随评价文字长短与图片张数自动变化（长文本自动换行、多图自动换行增高），拖动列宽或缩放窗口时自动重排；**列宽可拖拽调整、列顺序可拖动互换**
- **平滑滚动**：无极像素级滚动（非按行跳动），滚轮速度可调，滚动体验流畅
- **表格选择**：点内容单元格选中该格；点顶部字段名选中整列；点最左侧行号选中整行；**按住拖动可切换选中行**；无论光标在哪，点「修改记录」都编辑该条记录
- **批量选择**：表头「商品ID」左侧一个小复选框：点一下出现每行勾选框并默认全选，底部显示已选条数；取消个别行后半选状态，再点补齐全选；再点一下退出批量选择、勾选列消失
- **图片粘贴**：选中图片格后直接 **Ctrl+V**（也可双击占位格或右键粘贴），剪贴板截图自动保存本地并显示缩略图；**多图格 Ctrl+V 追加不替换**；点格内「+」从文件追加多张
- **图片管理**：多张评价图片格内并排显示，最多展示 5 张，超出有「展开」小按钮；**双击缩略图查看大图**（超过 800px 自动缩放，多张可翻页）；**右键图片可单独删除该张**；对着图片按 **Del** 也可删除指定图片；**Ctrl+C 复制图片到剪贴板**
- **文本双击编辑**：双击任意文本格可就地编辑，回车保存
- **商品链接列**：固定宽度 120px，内容过长不撑宽表格
- **标题搜索**：按标题关键词实时过滤当前店铺记录，支持一键清除
- **导出 Excel**：当前店铺全部记录导出为 `.xlsx`（表头加粗、列宽优化、多图字段换行拼接）

### 淘宝模块（v0.2 新增）

- **淘宝登录**：基于 **Playwright 驱动本机真实 Chrome** 扫码登录（非嵌入式浏览器，规避指纹风控）；严格以 `unb`/`tracknick` cookie 判登录，确认后访问「我的淘宝」真实验证；持久化 Chrome profile，登录态长期保留无需重复扫码
- **商品抓取**：粘贴淘宝商品链接，自动抓取**商品标题、价格、主图**（复用已登录 Chrome，先首页暖身再进商品页，反风控）；抓取结果展示标题/价格/商品ID/图片缩略图
- **风控应对**：真实 Chrome 指纹 + 持久化 profile + 反自动化参数 + 首页暖身，降低被淘宝「访问被拒绝」拦截的概率
- **日志系统**：淘宝模块全流程操作日志（登录、抓取、异常），按天分割保存到 `data/logs/`，保留 30 天，不上传 git

### 界面与性能

- **现代界面**：统一浅色主题（卡片式面板、圆角控件、状态色按钮），支持自定义 `app/style.qss`
- **左侧栏**：可拖拽边缘拉伸/折叠，带平滑过渡动画；折叠后拖出自动展开；右侧边框拖拽逻辑与左侧相反（先展开右侧内容再展开左侧店铺）
- **性能优化**：图片缩略图懒加载（仅渲染可见区域）+ 全局解码缓存（64MB），几百条记录的大店铺滚动、搜索、刷新不卡顿

    │   ├── __init__.py        # ImageService（图片保存/导入）、ExcelExporter

    │   ├── record_table.py    # 素材表格：勾选列、渲染、图片单元格、搜索
    │   ├── add_dialog.py      # 新增/修改素材记录弹窗
    │   ├── taobao_login_dialog.py   # 淘宝登录对话框（Playwright 真实 Chrome）
    │   ├── taobao_fetch_dialog.py   # 商品抓取对话框（粘贴链接→标题/价格/主图）
    │   ├── flow_layout.py     # 流式布局：多图自动换行、行高自适应

代码按「界面层 / 数据层 / 服务层 / 工具层」分层。后续新增记录字段只需修改 `app/config.py` 中的 `RECORD_FIELDS` 与 `TABLE_HEADERS`，表格渲染、搜索、导出自动跟随。

## 安装与运行

```bash
# 1. 克隆仓库
git clone https://github.com/GelunPan/taobao-material-tool.git
cd taobao-material-tool

# 2. 安装依赖（建议使用虚拟环境）
pip install -r requirements.txt

# 3. 安装 Playwright 浏览器驱动（首次使用淘宝模块需要）
playwright install chromium

# 4. 运行
python main.py
```

> **依赖说明**：`PyQt6>=6.5`、`playwright>=1.40`、`openpyxl>=3.1`、`requests>=2.31`。
> **淘宝登录**需要本机已安装 Chrome 浏览器（Playwright 调用系统真实 Chrome，非自带 Chromium）。
> 首次启动会自动创建 `data/` 目录（数据、图片、日志、Chrome profile 都在这）。

## 使用说明

### 基础操作

1. **新建店铺**：点击左侧「+ 新店铺」，输入店铺名称；**右键店铺可设置填充色/字体颜色**，方便区分
2. **选择店铺**：点击左侧店铺名，右侧表格展示该店铺素材记录；**双击店铺名展开/收起**
3. **新增记录**：点「新增记录」，填写商品ID、规格、标题、补手、评价、商品链接等；规格图/链接主图各选一张，**评价图片可多次「+ 添加图片」选多张**
4. **修改/复制/删除记录**：点中该条记录任意单元格（或行号选整行），点对应按钮；也可**右键**弹出菜单操作
5. **图片操作**：复制截图后点选图片格按 **Ctrl+V** 粘贴；多图格 Ctrl+V 追加；**双击缩略图查看大图**；右键/Del 删除指定图片；Ctrl+C 复制图片
6. **文本编辑**：**双击任意文本格就地编辑**，回车保存
7. **搜索**：右上角搜索框输入标题关键词，点「搜索」过滤；「清除搜索」恢复全部
8. **导出**：点「导出Excel」，选择保存位置，生成当前店铺全部记录的 `.xlsx`

### 淘宝登录与商品抓取

1. **淘宝登录**：点底部「淘宝登录」按钮 → 弹出登录对话框 → 点「打开 Chrome 登录」→ 自动打开真实 Chrome 窗口 → 用淘宝 APP 扫码 → 登录成功后自动验证并保存 cookie，按钮变为「淘宝已登录 ✓」
   - 已登录状态下点按钮可选择「重新登录」或「退出登录」
   - 登录态持久化保存在 `data/taobao_chrome_profile/`，下次启动自动恢复
2. **商品抓取**：点底部「抓取商品」按钮 → 弹出抓取对话框 → 粘贴淘宝商品链接 → 点「抓取」→ 后台自动打开 Chrome（先首页暖身再进商品页）→ 展示**商品标题、价格、商品ID、主图缩略图**
   - 抓取过程不阻塞界面，在工作线程运行
   - 需先完成淘宝登录，否则会提示先登录

> **风控提示**：淘宝有反爬机制，若抓取时出现「访问被拒绝」，建议：① 确保已登录且登录态有效；② 降低抓取频率，不要连续快速抓取多个商品；③ 稍等几分钟后重试。

## 数据安全

- 所有数据保存在程序目录下的 `data/` 中：
  - `data/data.json` — 店铺与记录数据
  - `data/images/` — 图片文件
  - `data/taobao_cookie.json` — 淘宝登录 cookie
  - `data/taobao_chrome_profile/` — Chrome 持久化 profile
  - `data/logs/` — 操作日志
- 图片字段记录的是本地文件路径，**移动/删除 `data/images/` 后缩略图会失效**
- `data/` 目录已在 `.gitignore` 中，不会上传到仓库
- **升级前请备份 `data/` 目录**
