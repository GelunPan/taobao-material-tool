# 淘宝评价工具

> 版本：**v1.2 正式版**（增量更新基线） · 本地离线桌面工具

面向淘宝运营/评价维护场景的素材管理工具：按店铺组织评价素材记录，支持截图直接粘贴进表格、按标题搜索、一键导出 Excel；内置淘宝登录与商品素材抓取（基于 Playwright 驱动本机真实 Chrome，规避风控）。全部数据保存在本地，不上传任何内容。

---

## 功能特性

### 素材管理（核心）

- **店铺 / 产品分类两级管理（v0.5）**：店铺下可建多个**产品分类**（分类一、分类二…，树上带记录数），素材按分类归档；右键店铺 → 新增产品分类 / 重命名店铺 / 删除店铺，右键分类 → 重命名 / 删除（最后一个分类不可删，同名分类自动合并），右键空白处 → 新增店铺；点击店铺自动落到第一个分类，点分类只看该分类记录
- **商品 ▾ 菜单（v0.5）**：底部「商品 ▾」一个入口汇聚 新增商品 / 修改商品信息 / 复制商品信息
- **快捷键（v0.5）**：**Ctrl+Z 撤销上一步数据操作**（快照式，覆盖增删改/复制/图片/店铺/分类等几乎全部操作）；**Ctrl+A 全选表格**
- **批量操作（v0.5）**：框选/勾选一片区域即选中这几条**完整记录**，右键批量删除、批量复制（在原位置下方插入副本）
- **店铺管理**：新增、重命名、删除店铺；店铺树实时显示素材数量；**拖拽店铺标签可排序**（带淡入高亮动效）；双击展开/收起；**右键店铺可设置填充色和字体颜色**（按店铺持久化记忆，重启不丢），导出表单图片的标题带同色
- **素材记录管理**：每条记录含 9 个字段——商品ID、规格图、规格、标题、链接主图、补手、买家秀评价、评价图片、商品链接；支持新增、修改、**复制（在原行下方生成相同记录并弹出表单可微调）**、删除；**评价图片支持多张**，表格内并排显示
- **自适应表格**：行高随评价文字长短与图片张数自动变化（长文本自动换行、多图自动换行增高），拖动列宽或缩放窗口时自动重排；**列宽可拖拽调整、列顺序可拖动互换**
- **平滑滚动**：无极像素级滚动（非按行跳动），滚轮速度可调，滚动体验流畅
- **表格选择**：点内容单元格选中该格；点顶部字段名选中整列；点最左侧行号选中整行；**按住拖动可切换选中行**；无论光标在哪，点「修改记录」都编辑该条记录
- **批量选择**：点表格左上角的「选择」按钮进入批量选择——每行左侧出现勾选框（默认未选），底部实时显示「已选 N 条」；**勾选列表头同时出现一个「全选」复选框**，勾上即全选、取消即全不选，只选了一部分时呈半选态（半选态点击 = 全选）；再点左上角「取消选择」退出，勾选列随之隐藏
- **导出（一个入口三种出口）**：底部「导出 ▾」按钮 →
  - **导出 Excel 表格**：当前店铺当前分类全部记录导出为 `.xlsx`——首行店铺名大标题 + 表头居中 + **图片字段嵌入原图**（保持宽高比、单张显示高度/整列总宽自动封顶）+ 商品ID居中 + 链接列窄列宽存完整 URL（复制即用）；**目标文件正被 Excel/WPS 打开时给出友好占用提示**，不再裸报 Errno 13
  - **导出表单图片**：把当前分类的**整张表单完整渲染成一张图片**——滚动区外的行、全部列都在内，**图片顶部带店铺名**（右侧附记录数与时间，配色跟随店铺设置）；整体缩放至 75%（面积约 56%，清晰度与体积平衡），**导出成功后自动复制到剪贴板**，可直接 Ctrl+V；弹出保存位置，文件名默认为「店铺名_序号」，同时归档到截图历史
  - **截图历史**：查看全部归档截图（左侧缩略图列表 + 右侧按宽度铺满的预览），双击看大图；**大图支持滚轮缩放、按住左键拖动平移**，可切 适应宽度 / 适应窗口 / 实际大小；列表中右键可「查看大图」「另存为…」「在文件夹中显示」；顶栏「清空历史」二次确认后真删除；历史界面**只读**（屏蔽 Ctrl+C/右键复制/编辑/拖拽，防误操作）
- **图片粘贴**：选中图片格后直接 **Ctrl+V**（也可双击占位格或右键粘贴），剪贴板截图自动保存本地并显示缩略图；**多图格 Ctrl+V 追加不替换**；点格内「+」从文件追加多张
- **图片管理**：多张评价图片格内并排显示，最多展示 5 张，超出有「展开」小按钮；**双击缩略图查看大图**（超过 800px 自动缩放，多张可翻页）；**右键图片可单独删除该张**；对着图片按 **Del** 也可删除指定图片；**Ctrl+C 复制图片到剪贴板**
- **文本双击编辑**：双击任意文本格可就地编辑，回车保存
- **商品链接列**：固定宽度 120px，内容过长不撑宽表格
- **标题搜索**：按标题关键词实时过滤当前分类记录，支持一键清除

### 淘宝模块（v0.2 新增）

- **淘宝登录**：基于 **Playwright 驱动本机真实 Chrome** 扫码登录（非嵌入式浏览器，规避指纹风控）；只认登录后才会下发的硬标志 `unb`/`_nk_` 判登录（不认 `tracknick` 等访客也会有的 cookie），确认后访问「我的淘宝」真实验证；持久化 Chrome profile，登录态长期保留无需重复扫码
- **商品抓取**：粘贴淘宝商品链接，自动抓取**商品标题、价格、主图**（复用已登录 Chrome，先首页暖身再进商品页，反风控）；抓取结果展示标题/价格/商品ID/图片缩略图
- **一键导入**：底部「一键导入」按钮批量抓取当前店铺所有已填「商品链接」的商品信息并自动填入记录（商品ID/标题/规格/链接主图/SKU规格图）；先检测 cookie 登录态；单条失败自动跳过，不影响其他条目；已导入过的自动跳过；点击后弹出位于应用中央的加载动画实时显示进度
- **风控应对**：真实 Chrome 指纹 + 持久化 profile + 反自动化参数 + 首页暖身，降低被淘宝「访问被拒绝」拦截的概率
- **日志系统**：淘宝模块全流程操作日志（登录、抓取、异常），按天分割保存到 `data/logs/`，保留 30 天，不上传 git

### 界面与性能

- **现代界面**：统一浅色主题（卡片式面板、圆角控件、状态色按钮），支持自定义 `app/style.qss`
- **左侧栏（v0.5 重构）**：可拖拽拉伸 / 折叠，平滑过渡动画；**左栏宽度由中间拖动缝唯一控制**（窗口边框缩放只伸缩右栏表单区、永不动左栏），展开态夹在 73~330px；折叠后窄轨拖出自动展开（≥120 切换完整面板，未拖出松手回弹窄轨）；中间为自绘 6px 拖动缝，悬停/按住变蓝
- **性能优化**：图片缩略图懒加载（仅渲染可见区域）+ 全局解码缓存（64MB），几百条记录的大店铺滚动、搜索、刷新不卡顿
- **增量渲染**：追加记录只重建新增行（不整表重建），无闪动、不打断滚动位置、保留已有勾选；配合滚动条缓动动画自然滚到新行

## 打包成安装程序（exe）

把源码打包成一个**极简安装向导 exe**：运行后**选安装位置 → 点安装 → 在桌面创建快捷方式**，无需 Inno Setup / NSIS。

### 打包前提

- **操作系统**：Windows 10/11（PyInstaller 跨平台，但本工具依赖 Qt WebEngine + Playwright，只在 Windows 验证）
- **本机 Python 环境**：已安装 `PyInstaller`、项目依赖（`PyQt6`、`PyQt6-WebEngine`、`playwright` 等），且与 `requirements.txt` 一致
- 打包机已执行过 `playwright install chromium`（淘宝模块依赖的浏览器驱动）

### 🔧 推荐：使用专用打包虚拟环境（避免系统 Python 污染，结果可复现）

项目已预置一个干净的打包虚拟环境，只包含项目真正需要的依赖，确保打包结果一致、不会把系统里无关的包打进去。

```bash
# 虚拟环境路径（已创建好，直接用）
D:\tools\python\envs\taobao-build

# 用虚拟环境的 Python 一键打包（约 3.5 分钟）
D:\tools\python\envs\taobao-build\Scripts\python.exe installer\build_all.py
```

如果需要从头重建这个虚拟环境（换机器 / 环境损坏时）：

```bash
# 1. 创建虚拟环境
python -m venv D:\tools\python\envs\taobao-build

# 2. 安装项目依赖 + PyInstaller
D:\tools\python\envs\taobao-build\Scripts\python.exe -m pip install PyQt6 PyQt6-WebEngine openpyxl Pillow requests playwright pyinstaller

# 3. 打包
D:\tools\python\envs\taobao-build\Scripts\python.exe installer\build_all.py
```

> **为什么用虚拟环境打包？**
> - 确保只打包项目真正需要的依赖，不会把系统 Python 里的杂包打进去
> - 打包结果可复现，换机器 / 换时间打包结果一致
> - 不会因为系统 Python 升级 / 安装新包而影响打包结果
> - 本项目体积主要由 PyQt6 + WebEngine（~300MB）+ playwright driver（~50MB）决定，虚拟环境不会显著减小体积，但能保证干净可复现

### 打包踩坑记录（改打包脚本前必读）

这一节记录的是**真实踩过的坑**，都是脚本层面修过但原理要记住的，避免以后返工。

#### 🔴 坑 1：`--add-data` 的目标路径必须是「目录」，不能写全文件名

错误写法（会报 `PermissionError: Permission denied: .../_internal/app/style.qss`）：

```bash
--add-data "app/style.qss:app/style.qss"   # ❌
```

PyInstaller 会把 `src` 的内容放进 `dest` 目录，于是 `style.qss` 被塞进一个同名**目录**
`_internal/app/style.qss/style.qss`；而 `main.py` 读的是 `_internal/app/style.qss`（此时是目录），
Windows 对目录 `open()` 报 **Permission denied**——报错信息完全看不出是路径写错了。

正确写法（`dest` 写父目录）：

```bash
--add-data "app/style.qss:app"   # ✅ 落到 _internal/app/style.qss（文件）
```

已固化在 `installer/build_app.py`，**不要手写这条命令**。

#### 🔴 坑 2：本环境「删除」被安全策略拦截（safe-delete）

删除操作（`os.remove` / `shutil.rmtree` / `cmd del` / `Remove-Item`）会被拦截并改走回收站，
回收站失败时直接**硬阻断**，且抛的是 `SystemExit`（`except Exception` 抓不到）。经验：

- **目录**：走外部 `cmd /c rmdir /s /q` 通常可行（已封装成 `build_app._safe_remove`）
- **文件**：大概率被阻断，尽量**不要依赖删除旧产物**
- 规避思路：让 PyInstaller 用独立 `--distpath`/`--workpath` 构建到临时目录，
  再用 `shutil.copy` 覆盖到最终位置（**写操作不受拦截**）——`build_installer.py` 用的就是这招

#### 🔴 坑 3：旧 exe 被进程占用 → 覆盖失败 `Permission denied`

Windows 会锁定「正在运行」的 exe 文件。若之前跑过 `--test` 或安装器且**进程没退出**
（它在后台能挂十几分钟），重建时覆盖 `dist/...安装程序.exe` 就会 Permission denied。

排查：结束残留的 `淘宝评价工具安装程序.exe` 进程后再重建。

#### 坑 4：GBK 控制台编码

- `--test` 模式 `print("...✅")` 会抛 `UnicodeEncodeError`（GBK 编码不了 emoji）→ 已用 `_safe_log` 兜底
- 创建快捷方式时 PowerShell 输出是 GBK，用 `capture_output=True` 会让 Python 读取线程解码失败并**永久挂起**
  → 已改为 `stdout/stderr=DEVNULL`（**这个坑会让真实安装卡在「创建快捷方式」**）

### 打包后自检

```bash
# 无界面跑完整安装流程（解压 + 桌面快捷方式），验证产物是否可用
dist/win10_x64_taobaotools_V1.2.exe --test D:/tmp_test_install
```

重点确认：`_internal/app/style.qss` 是**文件**而不是目录（坑 1 的直接验证点）。

### 目标机器注意事项

- **本机需有 Chrome 或 Edge**：淘宝登录/抓取调用系统真实浏览器（二选一，登录对话框里可切换）；Windows 自带 Edge 即可，无需另装 Chrome
- 安装程序**不含** Playwright 的 Chromium 内核下载；开发机打包时已就绪，分发到同机直接用即可；若换到未装驱动的环境，需先在目标机执行 `playwright install chromium`

## 使用说明

### 基础操作

1. **新建店铺**：点击左侧「+ 新店铺」，输入店铺名称；**右键店铺可设置填充色/字体颜色**，方便区分
2. **选择店铺**：点击左侧店铺名，右侧表格展示该店铺素材记录；**双击店铺名展开/收起**
3. **新增记录**：点「新增记录」，填写商品ID、规格、标题、补手、评价、商品链接等；规格图/链接主图各选一张，**评价图片可多次「+ 添加图片」选多张**
4. **修改/复制/删除记录**：点中该条记录任意单元格（或行号选整行），点对应按钮；也可**右键**弹出菜单操作
5. **图片操作**：复制截图后点选图片格按 **Ctrl+V** 粘贴；多图格 Ctrl+V 追加；**双击缩略图查看大图**；右键/Del 删除指定图片；Ctrl+C 复制图片
6. **文本编辑**：**双击任意文本格就地编辑**，回车保存
7. **搜索**：右上角搜索框输入标题关键词，点「搜索」过滤；「清除搜索」恢复全部
8. **批量选择**：点表格左上角「选择」按钮 → 每行左侧出现勾选框、勾选列表头出现「全选」复选框 → 勾选要操作的行（或点「全选」一键全选）；底部实时显示「已选 N 条」；再点左上角按钮退出
9. **导出**：点底部「导出 ▾」按钮，菜单里选：
   - **导出 Excel 表格**：选保存位置，生成当前店铺全部记录的 `.xlsx`
   - **导出表单图片**：选保存位置（默认文件名「店铺名_序号」），生成整张表单的完整图片（含滚动区外的行，顶部带店铺名），并自动归档到截图历史
   - **截图历史**：浏览全部归档截图；双击看大图，**大图里滚轮可缩放、按住左键可拖动平移**

> 店铺**重命名**：在左侧店铺列表上**右键 → 重命名**（左侧按钮栏只保留「+ 新店铺」「删除店铺」）。

### 淘宝登录与商品抓取

1. **淘宝登录**：点底部「淘宝登录」按钮 → 弹出登录对话框 → **下拉选择 Chrome 或 Edge**（自动探测本机已装浏览器）→ 点「打开浏览器登录」→ 自动打开所选浏览器窗口 → 用淘宝 APP 扫码 → 登录后自动访问「我的淘宝」**真实验证**并保存 cookie，按钮变为「淘宝已登录 ✓」
   - 已登录状态下点按钮可选择「重新登录」或「退出登录」
   - 必先扫码成功才报「登录成功」：若浏览器里残留的历史登录信息已失效，会自动清除并要求重新扫码，不会出现"假成功"
   - 「退出登录」会同时清除本地 cookie 与浏览器 profile 里的登录信息，状态可信、不留残留
   - 登录态持久化保存在 `data/taobao_chrome_profile/`（Chrome）或 `data/taobao_edge_profile/`（Edge），两浏览器独立目录互不干扰，下次启动自动恢复
2. **商品抓取**：点底部「抓取商品」按钮 → 弹出抓取对话框 → 粘贴淘宝商品链接 → 点「抓取」→ 后台自动打开 Chrome（先首页暖身再进商品页）→ 展示**商品标题、价格、商品ID、主图缩略图**
   - 抓取过程不阻塞界面，在工作线程运行
   - 需先完成淘宝登录，否则会提示先登录
3. **一键导入**：点底部「一键导入」按钮 → 自动筛选当前店铺中已填「商品链接」但尚未导入的记录 → 启动一个 Chrome 会话按序抓取 → 抓取成功的自动填入商品ID/标题/规格/链接主图/SKU规格图（图片下载到本地）；失败的自动跳过；已导入过的也自动跳过
   - 点击后弹出位于应用中央的加载动画，实时显示「正在导入 N/M：链接」
   - 数据逐条落库，进程意外中断也不会丢已导入的部分
   - 单条刷新可用商品链接列右键「抓取并填充到此行」

> **风控提示**：淘宝有反爬机制，若抓取时出现「访问被拒绝」，建议：① 确保已登录且登录态有效；② 降低抓取频率，不要连续快速抓取多个商品；③ 稍等几分钟后重试。

### 客户侧更新流程

1. 把更新包 `tb_tools_update_Vx.x.zip` 发给客户
2. 客户把 zip 放到**桌面**（更新器也会自动搜下载目录）
3. 客户双击桌面「**更新器**」图标
4. 更新器自动：
   - 找桌面/下载目录里 `tb_tools_update_V*.zip`
   - 读 zip 里的版本号，和当前安装的 `version.txt` 对比
   - 新版本号 ≤ 当前版本 → 拒绝更新
   - 关主程序 → 解压覆盖改动文件（**跳过 `data/` 目录，用户数据不丢**）→ 写新版本号 → 自动重启主程序
5. 更新完成，主程序自动打开

### 开发者发版流程（每次小更新都这么走）

```bash
# ============================================
# 前提：代码已改好、测试通过
# ============================================

# 1. 改版本号（app/config.py）
#    APP_VERSION = "1.4.0"
#    APP_VERSION_NAME = "v1.4 正式版"

# 2. 打增量更新包（约3分钟，自动对比上次的文件快照）
D:\tools\python\envs\taobao-build\Scripts\python.exe installer\build_update.py

# 3. 产物在 dist/tb_tools_update_V1.4.0.zip（通常几 MB ~ 几十 MB）
#    把这个 zip 发给客户即可
```

### 什么时候需要重新打完整安装包？

- **第一次给新客户**：发完整安装包 `win10_x64_taobaotools_Vx.x.exe`（~280MB）
- **改了更新器本身**（updater.py）：需要重新打完整包，因为更新器.exe 是初始安装时装进去的
- **加了新 pip 依赖**：build_update.py 会自动把 `_internal` 里的新 DLL/库文件打进 zip，但如果变化太大，建议重新打完整包测试

### 关键文件

| 文件 | 作用 |
|------|------|
| `installer/updater.py` | 更新器源码（找包、版本对比、关主程序、覆盖、重启） |
| `installer/更新器.exe` | 更新器编译产物（35MB，已进 git，固定不变除非改 updater.py） |
| `installer/build_update.py` | 增量打包脚本（对比 prev 快照，自动只打改动文件） |
| `app/config.py` | `APP_VERSION` 版本号，每次发版必改 |
| `dist/tb-tool2_prev/` | 上次构建的文件快照（build_update.py 自动维护） |

### 注意事项

- **改完代码打更新包前**，build_update.py 会自动清理旧构建，但如果遇到新旧 exe MD5 一样的奇怪情况，手动删 `build/`、`dist/tb-tool2/`、`tb-tool2.spec`、所有 `__pycache__` 再重打
- **更新器.exe 重新打包**：删 `installer/更新器.exe` 后跑 `build_update.py`，它会自动重打
- **更新包命名**：必须是 `tb_tools_update_Vx.x.x.zip`，更新器靠这个命名规则找包
- **用户数据安全**：更新器只覆盖程序文件，`data/` 目录（店铺数据、图片、cookie）永远不动

## 开发环境搭建（新电脑/家里电脑）

### 1. 装 Python

装 **Python 3.13.x**（64位），勾 "Add Python to PATH"。

### 2. 克隆代码

```bash
git clone https://jihulab.com/gelunpan/tb-tools.git
cd tb-tools
```

### 3. 建虚拟环境

```bash
# 在项目根目录建虚拟环境
python -m venv D:\tools\python\envs\taobao-build

# 激活
D:\tools\python\envs\taobao-build\Scripts\activate

# 装依赖
pip install PyQt6 playwright openpyxl pillow requests
playwright install chromium
```

### 4. 跑起来

```bash
D:\TOOLS\python\python.exe main.py
```

> 注意：开发时用主 Python（`D:\TOOLS\python\python.exe`），打包用虚拟环境（`D:\tools\python\envs\taobao-build\Scripts\python.exe`）。

### 5. 打包发布

#### 首次完整安装包（发客户）

```bash
D:\tools\python\envs\taobao-build\Scripts\python.exe installer\build_all.py
```
输出：`dist/win10_x64_taobaotools_Vx.x.exe`

#### 增量更新包（以后小更新）

```bash
D:\tools\python\envs\taobao-build\Scripts\python.exe installer\build_update.py
```
输出：`dist/tb_tools_update_Vx.x.zip`

把这个 zip 发给客户，让他们放到桌面，双击桌面「更新器」图标即可自动更新。

### 6. 目录说明

| 目录 | 说明 |
|------|------|
| `app/` | 主程序源码（UI、服务、存储） |
| `installer/` | 安装/打包脚本 |
| `data/` | 运行时数据（gitignore） |
| `dist/` | 打包输出（gitignore） |
| `app/assets/` | 图标、SVG 素材（git 同步） |

### 7. 更新器说明

- 更新器.exe 在 `installer/更新器.exe`，已打进 git
- 首次安装时它会被释放到安装目录，桌面创建「更新器」快捷方式
- 更新时它自动找桌面/下载目录的 `tb_tools_update_V*.zip`
- 版本号在 `app/config.py` 的 `APP_VERSION`，每次发版前改一下
